Information

The character set contains 26 monolinear letters that are created as the result of a matrix of predefined rules.

Form-finding

Once we established rules for every coordinate on the grid, we took turns drawing without targeting a specific letter. We began at the top-left node and advanced our starting point by one coordinate with each turn, stopping only when we both recognized an emerging letterform.

Digitization

After scanning the drawing sheets, we recreated the stroke paths for each letter. Every character shares the same total width, matching the size of the grid box, while the sidebearings remain true to the original sketches.
